# Public release approval checklist (not a certificate)

The code and derived-result tables are visible in a public **author-review snapshot**. Before an approved, tagged software release or Zenodo deposit, confirm in writing:

- [ ] All six coauthors approve publishing the reproduction code and derived analysis outputs.
- [ ] Copyright ownership and license for the code are confirmed; add an appropriate explicit `LICENSE` file (do not infer MIT or CC BY permissions).
- [ ] All original MAT measurements, historical copied illustrations, and rights-sensitive data are excluded or covered by a verified redistribution license.
- [ ] Clean-clone tests reproduce all headline results **after original inputs are acquired and validated**.
- [ ] `CITATION.cff` contains approved authors and release metadata.
- [ ] The manuscript's data/code availability wording matches this release and never invents a Zenodo DOI.
- [ ] Any Zenodo release uses a frozen Git commit and consistent release content.
