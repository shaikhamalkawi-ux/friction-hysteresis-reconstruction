# Contributing to this public research repository

You do **not** need to be a paper author to read, download or run the public code. GitHub users may report issues or submit a fork-based pull request. Direct pushes to this repository remain under maintainer control.

Before proposing a code change:

1. Explain its scientific scope, source provenance, environment and how you tested it.
2. Preserve the published/frozen evaluation protocols, exact numerical results, existing citation and source-identity manifests. Propose new experiments separately instead of silently replacing retained results.
3. Never submit third-party raw force/displacement measurements, original JSON/MAT/DAT/TDMS archives, private correspondence, personal data, credentials, journal submission files, or unpublished proprietary material.
4. Apply the existing MIT code-license notices only to eligible author-created software. Dataset and source-derived artifact rights remain separately governed by upstream licences and attribution requirements.
5. Distinguish derived-only checks from verified original-source raw reruns. A successful CI job does not establish independent physical validation.

Please use a GitHub Issue for reproducibility problems and provide the exact command, Python and dependency versions, and an error log without restricted data.

The current manuscript and software citation metadata remain subject to author-controlled release and affiliation confirmation.
